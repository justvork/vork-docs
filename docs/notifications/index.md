# Notifications

This section helps you send notifications with confidence.

You will learn:
- which provider types are supported today,
- where notifications are sent from (tools and built-in app flows), and
- how to prevent duplicate messages with idempotency.

## Start Here

- [Notification Basics](notification-basics.md)

## Notification Tools Index

Use these tools when you want to send, track, or audit notifications.

| Tool | Quick description | Full definition |
|---|---|---|
| listNotificationProviders | Shows which configured providers can send directly to an email address or phone number. | [listNotificationProviders](../tool-directory/list-notification-providers.md) |
| sendNotification | Sends a notification to one destination address using the provider you choose. | [sendNotification](../tool-directory/send-notification.md) |
| listNotificationLedgerEntries | Shows detailed send history rows, including success, failure, and duplicate suppression states. | [listNotificationLedgerEntries](../tool-directory/list-notification-ledger-entries.md) |
| summarizeNotificationLedger | Shows summary counts so you can quickly check notification health. | [summarizeNotificationLedger](../tool-directory/summarize-notification-ledger.md) |
| requestInformation | Can optionally send notification links to channels when requesting a response from people. | [requestInformation](../tool-directory/request-information.md) |
| createAttentionAlert | Creates an attention alert and can include an action link that people can follow. | [createAttentionAlert](../tool-directory/create-attention-alert.md) |
